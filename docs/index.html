System Design

3-Layer Architecture

From RFID chip to cloud — a complete IoT pipeline.

⚡
Layer 1

Embedded Layer

ESP32 / Arduino

Reads RFID tags via SPI protocol. Maintains a local product cache and streams scan events over MQTT/Serial to the edge gateway.

→
🔄
Layer 2

Edge Gateway

Raspberry Pi

Aggregates scan data via MQTT. Handles local conflict resolution, offline buffering, and forwards events to the cloud backend.

→
☁️
Layer 3

Cloud Backend

Node.js + Express + SQLite

Stores inventory, processes cart transactions, runs analytics, and serves both the admin dashboard and mobile shopper interface.

RFID → MQTT → Edge
Edge → REST API → DB
DB → React Frontend → User
