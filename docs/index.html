System Design

3-Layer IoT Architecture

From RFID chip to cloud — a complete hardware-to-AI pipeline.

⚡
Layer 1 — Embedded

ESP32 / Arduino

RFID · SPI · Local Cache

Reads RFID tags via SPI protocol. Maintains a local product cache and streams scan events over MQTT/Serial to the edge gateway.

→
🔄
Layer 2 — Edge Gateway

Raspberry Pi

MQTT · Conflict Resolution

Aggregates data, handles offline buffering, resolves conflicts, and syncs with the cloud backend in real time.

→
☁️
Layer 3 — Cloud+AI

Node.js + Express + Gemini

REST API · SQLite · Gemini AI

Stores inventory, processes transactions, runs analytics, serves the React dashboard, and powers AI recommendations.

RFID → MQTT → Edge
Edge → REST API → DB
DB → React UI → User
